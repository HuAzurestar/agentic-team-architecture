# 工作流 06：失败备案归档与统一索引

> RC（及研究线）的实验 / 路线失败备案，镜像进 CKO 知识体系归档与统一索引，跨中心可查可引。源台账由 RC 维护（源真），CKO 做镜像归档。

## 目的

失败是研究的正常产出，**沉淀为可查可引的知识资产**，避免同一路线反复踩坑、也避免失败经验丢失。

## 触发

- RC / CRO 新增或更新失败备案结构化条目。
- CKO 例行轮次（[工作流 01](01-knowledge-routine.md)）核对归档完整度。

## 步骤

1. **接收结构化条目**：RC 提交失败备案，字段必须包含——**ID、路线/实验、假设、结果、证据引用、驳回原因、日期、NEX 关联**；缺字段退回补齐。
2. **以 NEX 关联为锚点归档**：归档条目以 NEX 关联为**最小可引用单元**；无 NEX 的先用 ID 占位，后续补链。
3. **更新统一索引**：把新条目登记进 CKO 知识体系统一索引（跨中心可查）。
4. **同步校验**：源台账由 **RC 维护（源真）**；RC 新增 / 更新条目时同步归档；CKO 只镜像不篡改。
5. **数据真实性**：条目内容以 RC 源台账为准，**不编造、不美化**；发现数据矛盾反馈 RC 核对。

## 出口物

- 归档条目（以 NEX 关联为锚点的最小可引用单元）。
- 统一索引最新版。

## 负责角色

- **RC / CRO**：维护源台账（源真），提交 / 更新条目。
- **CKO**：镜像归档 + 统一索引（[docs/02-boundaries.md](../docs/02-boundaries.md) §1.6）。
