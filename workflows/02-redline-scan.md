# 工作流 02：红线扫描与处置

> "可以蠢，不能越权"的可观测检测流程。判定依据 = 红线手册（S0/S1/S2）；扫描由低成本角色高频执行，处置按级别分级。

## 目的

及早发现越权动作，按级别处置并复盘，把新的越权形态回填到红线手册。

## 触发

- **S0**：10min ~ 1h 一次（与例行推动同频，触发器到点统一触发）。
- **S1**：1h ~ 2h 一次。
- **S2**：每日 / 每周（AS 复核）。
- 初始建议值（单人 OPC）：S0 30min / S1 2h / S2 每日。**扫描、审计、报告都做时间留痕**（何时触发、扫描结果、处置动作）。

## 步骤

1. **扫描**：按红线手册 §2/§3/§4 与 §6 示例，扫描可见动作（越权发布 / 配置变更 / 对外口径 / issue 操作 / 成本档位）。
2. **分级**：对照红线手册认定 S0/S1/S2；手册之外的疑点走[工作流 04](04-escalation-triage.md)。
3. **处置**：
   - S0 → **紧急叫停** + 通知 AS → AS **紧急通知 CEO**（告警由 Autopilot 规则触发）。
   - S1 → 通知，不叫停；影响扩大可能上升 S0。
   - S2 → 汇报即可。
4. **复盘**：红线触发 → 立即纠正并复盘，记录到迭代复盘（[docs/05-iteration.md](../docs/05-iteration.md)），根因后更新边界 / 手册。

## 出口物

- 扫描记录（时间轴）+ 处置结果。
- 红线手册 / 边界文档的新增或调整。

## 负责角色

- **扫描**：Assistant AS / 安全角色（低成本）。
- **复核**：AS 低频复核。
- **认定与回填**：CKO。
- **最终处置**：CEO 拍板（S0）。
