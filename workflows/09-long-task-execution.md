# 工作流 09：长任务执行协议（CEO 一键运行）

> 小时级算力 / 数据长任务的统一执行协议（CEO 指令 `0d4909c2`，2026-08 启用；NEX-320/321/322/326/327/328 已按此执行）。把「冒烟 → 备份 + 实验号 → 报路径 → CEO 一键运行 → 回传」固定成可复用流程，避免长任务空转、结果不可追溯。

## 目的

长任务（算力 / 数据下载 / 全量实验）由 **CEO 一键运行**，Agent 不自持耗时代码执行——保证：① 冒烟先行，快速暴露接线错误；② 实验号 + 备份留痕，结果可追溯；③ 输入 / 输出路径对 CEO 透明；④ 约定位置回传，交付可核实。任何偏离（冒烟超时、自监听超时、数据不可得）如实留痕，不伪造。

## 触发

- 小时级长任务：统一框架实现（NEX-321）、消融全量实验（NEX-326）、数据全量腿构建（NEX-327）、归档打包（NEX-325）等算力 / 数据 / 存储密集型任务。

## 步骤

1. **冒烟通过**：先跑冒烟（小规模 / 子集）验证链路接线正确——**冒烟 ≤10min（无条件 ≤30min），超时记失败路径**，不进入正式运行。
2. **备份代码 + 实验号**：代码备份 + 申请 / 登记**实验号**（如 NEX326-ABL-FULL-001、NEX327-SLICES-001），随交付记录。
3. **报 CEO 输入 / 输出路径**：把输入路径（数据在哪儿）、输出路径（结果落哪儿）、运行命令一并交 CEO。
4. **CEO 一键运行**：CEO 在约定位置一键运行；Agent 不自持长时间前台执行。
5. **约定位置回传**：结果在约定位置落地后，Agent 核对统计 + 回传交付物 / 评论，交 CRO 把关 + 审核专员复核（按工作流 08）。
6. **Agent 自监听 ≤50min（有条件 ≤40min）**：运行时自监听，超时留痕上报；阻塞如实登记，不空转等待。

## 约束（红线相关）

- **数据必须有来源、不捏造**：外部配额 429 / 数据不可得时如实登记失败路径（如 NEX-328 Open-Meteo 429 外阻），不得伪造 / 回填模拟数据（红线手册 §6 #11 数据源真）。
- **失败臂如实记录入 RC 失败备案台账**（工作流 06），按预注册判据定胜负。
- 冒烟 / 运行超时按步骤 1 / 6 留痕，不静默硬凑。

## 出口物

- 冒烟结果（PASS/FAIL，含耗时）。
- 实验号 + 备份 + 输入 / 输出路径登记。
- 约定位置落地结果 + 回传交付评论（统计 / 出处 / 验收点）。
- 失败 / 阻塞如实登记（失败路径 / 台账）。

## 负责角色

- **发起方**（CTO / CRO / 研究助理等）：冒烟、备份、报路径、自监听、回传。
- **CEO**：一键运行 + 数据 / 配额类外部决断（如 API key）。
- **CRO**：把关收口；**审核专员**：五维复核（工作流 08）。
- **CKO**：红线合规对照（数据源真 / 不捏造）。
