# 工作流 04：升级三问与红线认定

> 可疑越权动作的复核与定级流程。红线手册之外的动作，按**升级三问**决定是否升级复核，由 **CKO** 认定 S0/S1/S2 并回填手册。

## 目的

把"越权疑点"标准化：先复核、再认定、后回填，避免执行者或探测者自行拍板。

## 触发

- 任一角色发现可疑越权动作。
- 红线手册（[docs/07-redline-manual.md](../docs/07-redline-manual.md)）命中但级别不明确。

## 步骤

1. **升级三问**（任一"是"→ 升级复核；三问皆"否"→ 正常执行 / 职责判断）：
   - 是否越权（对照 [docs/02-boundaries.md](../docs/02-boundaries.md) 角色规格与边界矩阵）？
   - 是否影响他中心 / 整体？
   - 是否不可逆 / 高风险？
2. **升级对象**：优先直属上级 / 小队 lead（AS / CKO 不一定有该事项裁量权），必要时逐级到 **AS / CKO**。
3. **认定级别**：CKO 对照红线手册认定 S0/S1/S2。
4. **处置**：按[工作流 02](02-redline-scan.md) 处置。
5. **回填**：不在手册的动作，认定后补充进红线手册 §6 示例表。

## 出口物

- 升级记录（问题、影响、已尝试方案、需要的决策）。
- 红线级别认定 + 处置结果。
- 红线手册新示例（如有）。

## 负责角色

- **升级对象**：直属上级 / 小队 lead / AS / CKO。
- **认定**：CKO。
- **最终处置**：CEO 拍板（S0 / 重大事项）。
