# C3/0.1: source projection and execution context

The read input identifies an environment, local authoritative feature directory, and current or selected task. A source stage may return refs, original text and a read only projection with diagnostics. It never grants `valid=true` execution. An execution stage requires the original Markdown/Git helper to validate the same source and return the real feature, task and task detail, selected requirement/solution text and decisions, repositories and refs, dependencies, trace, required gist/type contract/acceptance brief, and source locations. Failure has `context=null` plus diagnostics; a success with empty context or sources is invalid.

The profile is navigation support. It cannot decide a point or approve a task. Compare necessary facts with the original source, including blocker and refs. If the projection and source differ, return a mismatch; never splice some profile fields into a local execution result. If source members or content changed during the read, discard that read and repeat or report a source set change. Ordinary multi file reads are not a transaction and do not prove absence of ABA.

When SMMD is unavailable, the complete same source local Markdown set can be read directly and passed to the existing Git validation helper. A remote historical export or unrelated checkout cannot stand in for that source. Unknown optional display metadata may be ignored. Unknown required semantics or unsupported versions are rejected.

`C3-01` through `C3-09` cover direct/profile agreement, missing blocker, stale recorded SHA, source set change, unknown required feature, empty success, source only projection, mismatched provider source, and same source local fallback. Each static execution case carries authoritative source facts and the profile context separately; the checker compares every required execution fact and source list instead of trusting a same-source flag. These are illustrative captured facts, not a live source read; the checker does not replace `task_context.py` or its real Git probe.
