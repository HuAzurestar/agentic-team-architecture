# REQ-001 — Report invalid entries with a reason

## Core requirement

Invalid incoming entries must be reported with an understandable reason.

## Acceptance conditions

- A caller can identify the invalid entry and understand the reported reason.

## Design rationale and open questions

Extract the core need from the linked INT during detailed design. Preserve the INT rather than rewriting it as the requirement.
