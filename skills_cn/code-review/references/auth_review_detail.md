# 弱审：auth

一个入口保护正确不能证明所有数据出口正确。

- 披露/副作用前是否取得 actor、resource、scope、继承权限和数据使用限制？
- 单条、完整包、预览、下载、缓存、API/CLI、后台及导入导出是否有旁路？
- 外部 ID 或归属变化是否泄露其他用户数据，是否可指定特权上下文？
- 序列化、部分结果、元数据、错误和日志是否泄露受限字段？
- token/password/private payload 是否进入输出和持久诊断？
- 预览/校验后数据或权限改变，执行边界是否重新检查？
- 恢复、重试及服务身份是否扩大用户授权？
- 路径、URL、上传文件和不可信值是否在正确信任边界校验？

搜 authorize/permission/access 及 export/download/serialize/cache 的业务表达，追踪所有受限数据出口。使用授权的受限测试身份，断言受限读取/披露前拒绝；尝试外部对象 ID、继承限制、旧权限和替代输出。完整包通过不替代单条检查。
