# 弱审：regression

列出每处修改已有语义的地方，仅称未发现兼容问题不够。

- 既有含义、默认值、异常、空值、顺序或副作用是否改变？
- 旧 API、消费者、配置及工作流是否仍可用？
- 历史 schema/data 是否可读，迁移是否安全？
- 直接/间接调用方、注册入口、外部消费者是否覆盖？
- 删除符号是否还被插件、序列化或配置引用？
- 有效历史 bug 回归是否在新候选上执行？
- 生成产物、打包和支持版本是否与源代码一致？
- 旧证据和已接受行为是否对当前 target 有效，而非凭分支名继承？

追踪公共定义到调用方和同类路径。尝试旧输入/配置/数据、遗漏值及历史反例，必要时固定旧新版本比较。盲审可读普通现有测试，不读旧审查结论；固定快照后才从账本复核适用修复。没再次发现不等于关闭。
